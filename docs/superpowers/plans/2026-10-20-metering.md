# Metering, Cost Model and Pool Quota Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Limit each workspace's use of the shared source-account pool (a daily quota per platform plus an operator reserve), record every workspace's usage, and estimate its cost for platform admins.

**Architecture:**
- **One `metering` module** holds a context-variable *meter scope* (workspace, workflow, project) and a process-wide sink, the `UsageStore` on the editor database.
- **Where the scope is set:**
  - a Temporal activity interceptor sets it for every activity, from a `workspace_id` memo that the gateway writes when it starts a workflow;
  - `current_actor` sets it for every API request.
- **Quota and reserve:** checked inside `SourceAccountStore.lease()`, in the lease's own transaction, under one row lock.
- **Writers of usage events:**
  - the lease itself;
  - the workflow-run store, when a run first succeeds;
  - the render service, on completion;
  - a metered media store wrapper;
  - each provider adapter.
- **Readers:** admin routes and the CLI price and read the events; the dashboard gets a Usage page.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 ORM, Alembic SQL revisions, temporalio 1.34 interceptors, agno 3.1 `RunOutput.metrics`, React 19 + Bun tests, the Docker stack smoke.

**Spec:** `docs/superpowers/specs/2026-10-20-metering-design.md`

## Global Constraints

- **Default workspace quotas:** Instagram 3, TikTok 10, X 5, YouTube 10, Threads 5 leases per workspace per UTC day; `ws_bootstrap` is exempt.
- **Operator reserve:** `reserve = ceil(capacity × reserve_percent / 100)`, default 50.
  - A lease for a workspace other than `ws_bootstrap` is refused when `remaining − 1 < reserve`.
  - A platform with `daily_budget = 0` has no reserve.
- **Capacity** = the daily budget × the number of accounts that are `healthy`, or in a `cooldown` that ends before tomorrow 00:00 UTC. **Remaining** = Σ max(0, budget − uses today).
- **Over the quota or the reserve:** acquisition runs anonymously with `quota_exhausted = true`, and the workflow never fails.
- **Meter errors:** the meter never fails the work it measures. A sink error is a `warn`. With no sink installed, nothing is recorded.
- **Usage event kinds:** `account_lease`, `workflow_completed`, `video_rendered`, `media_stored`, `provider_call`.
- **Usage event units:** `session`, `workflow`, `second`, `byte`, `call`, `token_in`, `token_out`, `character`.
- **Prices and visibility:** prices are USD. Events without a price are `unpriced`, never zero. Users never see money.
- **Migration `0015`:** adds tables and one nullable column; nothing is dropped and nothing is backfilled.
- **Commits:** exactly one `git commit -m "<subject>"`, with no body, no trailer and no AI attribution (AGENTS.md).
- **Staging:** never stage `.superpowers/`, `graphify-out/`, `.serena/` or `design/`. Files under `docs/superpowers/` need `git add -f`.
- **Tests stay offline;** run Python tests from WSL with `make test T=…` and PostgreSQL tests with `make test-postgres`.
- **Naming:** the event timestamp column is `occurred_at`, not `at`, because `AT` is an SQL keyword. Everything else follows the spec's names.

## Review Focus

1. **A workflow's first activity runs before its `workflow_runs` row exists:** the meter scope must still name the right workspace (the memo), never `ws_bootstrap`. Pinned in Task 4.
2. **Two workspaces leasing at the same moment at the reserve line:** at most one lease. Pinned in Task 3 (PostgreSQL).
3. **A lease that fails to decrypt an account and retries:** it must not count twice against the quota. Pinned in Task 3: an event is written only on a returned lease.
4. **A render whose completion event is replayed:** it must not count a second video. Pinned in Task 5.
5. **A media write with no scope (the private renderer route, a CLI import):** it must not be charged to `ws_bootstrap`. Pinned in Task 5.

CREATE TABLE usage_events (
    event_id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL REFERENCES workspaces (workspace_id),
    workflow_id TEXT,
    project_id TEXT,
    kind TEXT NOT NULL CHECK (kind IN (
        'account_lease', 'workflow_completed', 'video_rendered', 'media_stored', 'provider_call'
    )),
    key TEXT NOT NULL,
    quantity DOUBLE PRECISION NOT NULL CHECK (quantity >= 0),
    unit TEXT NOT NULL CHECK (unit IN (
        'session', 'workflow', 'second', 'byte', 'call', 'token_in', 'token_out', 'character'
    )),
    occurred_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX usage_events_workspace ON usage_events (workspace_id, occurred_at);
CREATE INDEX usage_events_workspace_kind ON usage_events (workspace_id, kind, key, occurred_at);

CREATE TABLE workspace_quotas (
    workspace_id TEXT NOT NULL REFERENCES workspaces (workspace_id),
    platform TEXT NOT NULL,
    daily_leases INTEGER NOT NULL CHECK (daily_leases >= 0),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (workspace_id, platform)
);

CREATE TABLE unit_prices (
    kind TEXT NOT NULL,
    key TEXT NOT NULL,
    unit TEXT NOT NULL,
    usd_per_unit DOUBLE PRECISION NOT NULL CHECK (usd_per_unit >= 0),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (kind, key, unit)
);

ALTER TABLE source_account_policies ADD COLUMN operator_reserve_percent INTEGER
    CHECK (operator_reserve_percent BETWEEN 0 AND 100);

"""The meter scope, the sink and the cost estimate (spec 2026-10-20 metering, section 2)."""

import asyncio
from types import SimpleNamespace

from thoth_control_plane import metering
from thoth_control_plane.metering import MeterScope, UsageRecord


class Sink:
    def __init__(self, *, workflows=None, projects=None, fail=False) -> None:
        self.events: list[UsageRecord] = []
        self.workflows = workflows or {}
        self.projects = projects or {}
        self.fail = fail

    def record(self, event: UsageRecord) -> None:
        if self.fail:
            raise RuntimeError("database down")
        self.events.append(event)

    def workspace_of_workflow(self, workflow_id: str) -> str | None:
        return self.workflows.get(workflow_id)

    def workspace_of_project(self, project_id: str) -> str | None:
        return self.projects.get(project_id)


def test_a_record_carries_the_scope() -> None:
    sink = Sink()
    metering.install(sink)
    with metering.scoped(MeterScope("ws_a", workflow_id="wf_1", project_id="p1")):
        metering.record_sync("provider_call", "m", 1, "call")
    assert sink.events == [UsageRecord("ws_a", "provider_call", "m", 1.0, "call", "wf_1", "p1")]


def test_outside_any_scope_a_provider_call_goes_to_the_bootstrap() -> None:
    sink = Sink()
    metering.install(sink)
    metering.record_sync("provider_call", "m", 1, "call")
    assert sink.events[0].workspace_id == "ws_bootstrap"


def test_in_scope_only_records_nothing_outside_a_scope() -> None:
    sink = Sink()
    metering.install(sink)
    metering.record_sync("media_stored", "renders", 10, "byte", in_scope_only=True)
    assert sink.events == []


def test_a_failing_sink_never_fails_the_work() -> None:
    metering.install(Sink(fail=True))
    metering.record_sync("provider_call", "m", 1, "call")  # no exception


def test_no_sink_records_nothing() -> None:
    metering.install(None)
    metering.record_sync("provider_call", "m", 1, "call")


def test_a_model_run_records_the_call_and_its_tokens() -> None:
    sink = Sink()
    metering.install(sink)
    run = SimpleNamespace(metrics=SimpleNamespace(input_tokens=120, output_tokens=0))
    with metering.scoped(MeterScope("ws_a")):
        asyncio.run(metering.record_model_run("qwen", run))
    assert [(e.quantity, e.unit) for e in sink.events] == [(1.0, "call"), (120.0, "token_in")]


def test_the_scope_reaches_a_worker_thread() -> None:
    sink = Sink()
    metering.install(sink)

    async def main() -> None:
        with metering.scoped(MeterScope("ws_t")):
            await metering.record("provider_call", "m", 1, "call")

    asyncio.run(main())
    assert sink.events[0].workspace_id == "ws_t"


def test_a_workflow_scope_prefers_the_memo_then_the_run_row_then_the_bootstrap() -> None:
    metering.install(Sink(workflows={"wf_row": "ws_row"}))
    assert metering.workflow_scope("wf_x", "ws_memo") == MeterScope("ws_memo", workflow_id="wf_x")
    assert metering.workflow_scope("wf_row").workspace_id == "ws_row"
    assert metering.workflow_scope("wf_none").workspace_id == "ws_bootstrap"


def test_a_project_scope_names_the_projects_workspace() -> None:
    metering.install(Sink(projects={"p1": "ws_p"}))
    assert metering.project_scope("p1") == MeterScope("ws_p", project_id="p1")


def test_the_estimate_prices_known_items_and_reports_the_rest_unpriced() -> None:
    totals = [
        SimpleNamespace(kind="account_lease", key="instagram", unit="session", quantity=4.0),
        SimpleNamespace(kind="provider_call", key="qwen", unit="token_in", quantity=1000.0),
        SimpleNamespace(kind="video_rendered", key="p", unit="second", quantity=30.0),
    ]
    prices = {
        ("account_lease", "instagram", "session"): 0.05,
        ("provider_call", "*", "token_in"): 0.000001,
    }
    result = metering.estimate(totals, prices)
    assert round(result.usd, 6) == 0.201
    assert [(line.key, line.usd) for line in result.unpriced] == [("p", None)]

"""Usage metering (spec 2026-10-20 metering, section 2).

The meter scope says whose work runs now. A Temporal interceptor sets it for every activity, and
`current_actor` for every API request. `record` writes one usage event against it. The meter
never fails the work it measures: a sink error is a `warn`, and with no sink installed nothing
is recorded.
"""

from __future__ import annotations

import asyncio
import contextlib
import logging
import math
from collections.abc import Iterator, Mapping, Sequence
from contextvars import ContextVar
from dataclasses import dataclass
from typing import Any, Literal, Protocol

from thoth_control_plane.auth.models import BOOTSTRAP_WORKSPACE_ID

logger = logging.getLogger(__name__)

Kind = Literal[
    "account_lease", "workflow_completed", "video_rendered", "media_stored", "provider_call"
]
Unit = Literal["session", "workflow", "second", "byte", "call", "token_in", "token_out", "character"]
KINDS: frozenset[str] = frozenset(Kind.__args__)  # type: ignore[attr-defined]
UNITS: frozenset[str] = frozenset(Unit.__args__)  # type: ignore[attr-defined]


@dataclass(frozen=True)
class MeterScope:
    workspace_id: str
    workflow_id: str | None = None
    project_id: str | None = None


@dataclass(frozen=True)
class UsageRecord:
    workspace_id: str
    kind: str
    key: str
    quantity: float
    unit: str
    workflow_id: str | None = None
    project_id: str | None = None


class UsageSink(Protocol):
    def record(self, event: UsageRecord) -> None: ...
    def workspace_of_workflow(self, workflow_id: str) -> str | None: ...
    def workspace_of_project(self, project_id: str) -> str | None: ...


_scope: ContextVar[MeterScope | None] = ContextVar("thoth_meter_scope", default=None)
# ponytail: one process-wide sink; the API and the worker each install the editor database's.
_sink: UsageSink | None = None


def install(sink: UsageSink | None) -> None:
    global _sink
    _sink = sink


def installed() -> UsageSink | None:
    return _sink

    return _scope.get()


def enter_scope(scope: MeterScope | None) -> None:
    """Set the scope for the rest of this task; each API request runs in its own task."""
    _scope.set(scope)


@contextlib.contextmanager
def scoped(scope: MeterScope | None) -> Iterator[None]:
    token = _scope.set(scope)
    try:
        yield
    finally:
        _scope.reset(token)


def record_sync(
    kind: str, key: str, quantity: float, unit: str, *, in_scope_only: bool = False
) -> None:
    sink = _sink
    if sink is None:
        return
    scope = _scope.get()
    if scope is None:
        if in_scope_only:
            return
        logger.warning("usage outside a meter scope recorded for the bootstrap kind=%s", kind)
        scope = MeterScope(BOOTSTRAP_WORKSPACE_ID)
    try:
        sink.record(
            UsageRecord(
                scope.workspace_id,
                kind,
                key[:200],
                float(quantity),
                unit,
                scope.workflow_id,
                scope.project_id,
            )
        )
    except Exception:
        logger.warning("usage event not recorded kind=%s", kind)


async def record(kind: str, key: str, quantity: float, unit: str) -> None:
    if _sink is None:
        return
    # to_thread copies the context, so the scope travels with the write.
    await asyncio.to_thread(record_sync, kind, key, quantity, unit)


async def record_call(
    key: str,
    *,
    tokens_in: int | None = None,
    tokens_out: int | None = None,
    characters: int | None = None,
) -> None:
    """One provider call, with what the provider reported about its size."""
    await record("provider_call", key, 1, "call")
    for unit, value in (("token_in", tokens_in), ("token_out", tokens_out), ("character", characters)):
        if isinstance(value, int) and value > 0:
            await record("provider_call", key, value, unit)


async def record_model_run(model: str, run: Any) -> None:
    metrics = getattr(run, "metrics", None)
    await record_call(
        model,
        tokens_in=getattr(metrics, "input_tokens", None),
        tokens_out=getattr(metrics, "output_tokens", None),
    )


def _lookup(call: Any, value: str) -> str | None:
    try:
        return call(value)
    except Exception:
        logger.warning("meter scope lookup unavailable")
        return None


def workflow_scope(workflow_id: str, memo_workspace: str | None = None) -> MeterScope:
    """The memo the gateway wrote at start, else the run row, else the bootstrap (spec 1.2)."""
    workspace = memo_workspace
    if workspace is None and _sink is not None:
        workspace = _lookup(_sink.workspace_of_workflow, workflow_id)
    if workspace is None:
        logger.warning("a workflow without a known workspace is metered for the bootstrap")
        workspace = BOOTSTRAP_WORKSPACE_ID
    return MeterScope(workspace, workflow_id=workflow_id)


def project_scope(project_id: str) -> MeterScope | None:
    if _sink is None:
        return None
    workspace = _lookup(_sink.workspace_of_project, project_id) or BOOTSTRAP_WORKSPACE_ID
    return MeterScope(workspace, project_id=project_id)


@dataclass(frozen=True)
class CostLine:
    kind: str
    key: str
    unit: str
    quantity: float
    usd: float | None


@dataclass(frozen=True)
class Estimate:
    lines: tuple[CostLine, ...]
    usd: float
    unpriced: tuple[CostLine, ...]


def estimate(totals: Sequence[Any], prices: Mapping[tuple[str, str, str], float]) -> Estimate:
    """Σ quantity × unit price; a key of `*` prices every key of its kind and unit."""
    lines = []
    for total in totals:
        price = prices.get((total.kind, total.key, total.unit))
        if price is None:
            price = prices.get((total.kind, "*", total.unit))
        usd = None if price is None else total.quantity * price
        lines.append(CostLine(total.kind, total.key, total.unit, total.quantity, usd))
    priced = math.fsum(line.usd for line in lines if line.usd is not None)
    return Estimate(tuple(lines), priced, tuple(line for line in lines if line.usd is None))

class UsageTotal:

    key: str
    unit: str
    quantity: float
    events: int


@dataclass(frozen=True)
class UnitPrice:
    kind: str
    key: str
    unit: str
    usd_per_unit: float


def day_start(moment: datetime) -> datetime:
    return datetime.combine(moment.date(), datetime.min.time(), tzinfo=UTC)


class UsageStore:
    def __init__(
        self, engine: Engine, clock: Callable[[], datetime] = lambda: datetime.now(UTC)
    ) -> None:
        self._sessions = sessionmaker(engine, expire_on_commit=False)
        self._clock = clock

    @classmethod
    def connect(cls, database_url: str) -> UsageStore:
        url = make_url(database_url).set(drivername="postgresql+psycopg")
        return cls(
            create_engine(
                url,
                pool_pre_ping=True,
                pool_size=2,
                max_overflow=2,
                hide_parameters=True,
                connect_args={"connect_timeout": 10},
            )
        )

    def record(self, event: UsageRecord) -> None:
        with self._sessions.begin() as session:
            session.add(
                UsageEventRow(
                    event_id=f"use_{uuid.uuid4().hex}",
                    workspace_id=event.workspace_id,
                    workflow_id=event.workflow_id,
                    project_id=event.project_id,
                    kind=event.kind,
                    key=event.key,
                    quantity=event.quantity,
                    unit=event.unit,
                    occurred_at=self._clock(),
                )
            )

    def workspace_of_workflow(self, workflow_id: str) -> str | None:
        with self._sessions() as session:
            actor = session.scalar(
                select(WorkflowRunRow.actor_id).where(WorkflowRunRow.workflow_id == workflow_id)
            )
        return None if actor is None else actor_workspace_id(actor)

    def workspace_of_project(self, project_id: str) -> str | None:
        with self._sessions() as session:
            return session.scalar(
                select(ProjectRow.workspace_id).where(ProjectRow.project_id == project_id)
            )

    def _grouped(self, start: datetime, end: datetime, workspace_id: str | None):
        query = select(
            UsageEventRow.workspace_id,
            UsageEventRow.kind,
            UsageEventRow.key,
            UsageEventRow.unit,
            func.sum(UsageEventRow.quantity),
            func.count(),
        ).where(UsageEventRow.occurred_at >= start, UsageEventRow.occurred_at < end)
        if workspace_id is not None:
            query = query.where(UsageEventRow.workspace_id == workspace_id)
        query = query.group_by(
            UsageEventRow.workspace_id, UsageEventRow.kind, UsageEventRow.key, UsageEventRow.unit
        ).order_by(UsageEventRow.workspace_id, UsageEventRow.kind, UsageEventRow.key)
        with self._sessions() as session:
            return session.execute(query).all()

    def totals(self, workspace_id: str, start: datetime, end: datetime) -> list[UsageTotal]:
        return [
            UsageTotal(kind, key, unit, float(quantity), int(events))
            for _ws, kind, key, unit, quantity, events in self._grouped(start, end, workspace_id)
        ]

    def totals_by_workspace(self, start: datetime, end: datetime) -> dict[str, list[UsageTotal]]:
        found: dict[str, list[UsageTotal]] = {}
        for workspace, kind, key, unit, quantity, events in self._grouped(start, end, None):
            found.setdefault(workspace, []).append(
                UsageTotal(kind, key, unit, float(quantity), int(events))
            )
        return found

    def leases_today(self, workspace_id: str) -> dict[str, int]:
        start = day_start(self._clock())
        return {
            total.key: total.events
            for total in self.totals(workspace_id, start, start + timedelta(days=1))
            if total.kind == "account_lease"
        }

    def quotas(self, workspace_id: str) -> dict[str, int]:
        with self._sessions() as session:
            overrides = {
                row.platform: row.daily_leases
                for row in session.scalars(
                    select(WorkspaceQuotaRow).where(WorkspaceQuotaRow.workspace_id == workspace_id)
                )
            }
        return {
            platform: overrides.get(platform, DEFAULT_WORKSPACE_DAILY_LEASES.get(platform, 0))
            for platform in PLATFORMS
        }

    def set_quota(self, workspace_id: str, platform: str, daily_leases: int) -> None:
        if platform not in PLATFORMS or daily_leases < 0:
            raise ValueError("invalid_quota")
        with self._sessions.begin() as session:
            row = session.get(WorkspaceQuotaRow, (workspace_id, platform))
            if row is None:
                row = WorkspaceQuotaRow(workspace_id=workspace_id, platform=platform)
                session.add(row)
            row.daily_leases, row.updated_at = daily_leases, self._clock()

    def clear_quota(self, workspace_id: str, platform: str) -> None:
        with self._sessions.begin() as session:
            session.execute(
                delete(WorkspaceQuotaRow).where(
                    WorkspaceQuotaRow.workspace_id == workspace_id,
                    WorkspaceQuotaRow.platform == platform,
                )
            )

    def prices(self) -> list[UnitPrice]:
        with self._sessions() as session:
            rows = session.scalars(
                select(UnitPriceRow).order_by(UnitPriceRow.kind, UnitPriceRow.key, UnitPriceRow.unit)
            )
            return [UnitPrice(r.kind, r.key, r.unit, r.usd_per_unit) for r in rows]

    def set_price(self, kind: str, key: str, unit: str, usd_per_unit: float) -> UnitPrice:
        if kind not in KINDS or unit not in UNITS or not key or usd_per_unit < 0:
            raise ValueError("invalid_price")
        with self._sessions.begin() as session:
            row = session.get(UnitPriceRow, (kind, key, unit))
            if row is None:
                row = UnitPriceRow(kind=kind, key=key, unit=unit)
                session.add(row)
            row.usd_per_unit, row.updated_at = usd_per_unit, self._clock()
        return UnitPrice(kind, key, unit, usd_per_unit)

    def _check_quota(
        self,
        session: Session,
        workspace_id: str,
        platform: Platform,
        policy: PolicyView,
        now: datetime,
    ) -> None:
        """Spec 2026-10-20, 1.2 and 1.4: the workspace quota, then the operator reserve."""
        # One lock for every non-bootstrap lease: the reserve spans workspaces.
        session.get(WorkspaceRow, BOOTSTRAP_WORKSPACE_ID, with_for_update=True)
        today = now.date()
        start = datetime.combine(today, datetime.min.time(), tzinfo=UTC)
        override = session.get(WorkspaceQuotaRow, (workspace_id, platform))
        limit = (
            override.daily_leases
            if override is not None
            else DEFAULT_WORKSPACE_DAILY_LEASES.get(platform, 0)
        )
        used = session.scalar(
            select(func.count())
            .select_from(UsageEventRow)
            .where(
                UsageEventRow.workspace_id == workspace_id,
                UsageEventRow.kind == "account_lease",
                UsageEventRow.key == platform,
                UsageEventRow.occurred_at >= start,
            )
        )
        if (used or 0) >= limit:
            raise QuotaReached("workspace_quota")
        if policy.daily_budget <= 0:
            return  # an unlimited budget has no reserve
        tomorrow = start + timedelta(days=1)
        ids = list(
            session.scalars(
                select(SourceAccountRow.id).where(
                    SourceAccountRow.platform == platform,
                    or_(
                        SourceAccountRow.status == "healthy",
                        and_(
                            SourceAccountRow.status == "cooldown",
                            SourceAccountRow.cooldown_until < tomorrow,
                        ),
                    ),
                )
            )
        )
        uses = dict(
            session.execute(
                select(SourceAccountUsageRow.account_id, SourceAccountUsageRow.uses).where(
                    SourceAccountUsageRow.account_id.in_(ids),
                    SourceAccountUsageRow.day == today,
                )
            ).all()
        )
        remaining = sum(max(0, policy.daily_budget - uses.get(i, 0)) for i in ids)
        reserve = math.ceil(len(ids) * policy.daily_budget * policy.operator_reserve_percent / 100)
        if remaining - 1 < reserve:
            raise QuotaReached("operator_reserve")

"""Every activity runs in its workflow's meter scope (spec 2026-10-20 metering, 2.2).

The gateway writes the workspace into the workflow memo when it starts the workflow, so the
scope is right even when the first activity runs before the `workflow_runs` row is written.
"""

from __future__ import annotations

import asyncio
import logging
from typing import Any

from temporalio import activity
from temporalio.worker import ActivityInboundInterceptor, ExecuteActivityInput, Interceptor

from thoth_control_plane import metering

logger = logging.getLogger(__name__)


async def _memo_workspace(client: Any, workflow_id: str) -> str | None:
    try:
        description = await client.get_workflow_handle(workflow_id).describe()
        workspace = (await description.memo()).get("workspace_id")
    except Exception:
        logger.warning("workflow memo unavailable; the meter scope falls back")
        return None
    return workspace if isinstance(workspace, str) else None


class _ScopedActivity(ActivityInboundInterceptor):
    def __init__(self, next: ActivityInboundInterceptor, client: Any) -> None:
        super().__init__(next)
        self._client = client

    async def execute_activity(self, input: ExecuteActivityInput) -> Any:
        workflow_id = activity.info().workflow_id
        memo = await _memo_workspace(self._client, workflow_id)
        scope = await asyncio.to_thread(metering.workflow_scope, workflow_id, memo)
        with metering.scoped(scope):
            return await super().execute_activity(input)


class MeterScopeInterceptor(Interceptor):
    def __init__(self, client: Any) -> None:
        self._client = client

    def intercept_activity(self, next: ActivityInboundInterceptor) -> ActivityInboundInterceptor:
        return _ScopedActivity(next, self._client)
```

def _month_range(month: str | None) -> tuple[str, datetime, datetime]:
    now = datetime.now(UTC)
    year, number = (int(part) for part in (month or now.strftime("%Y-%m")).split("-"))
    start = datetime(year, number, 1, tzinfo=UTC)
    end = datetime(year + number // 12, number % 12 + 1, 1, tzinfo=UTC)
    return f"{year:04d}-{number:02d}", start, end

    return sum(t.events for t in totals if t.kind == kind)


@router.get("/usage", response_model=UsageView)
async def my_usage(
    request: Request,
    principal: Caller,
    month: Annotated[str | None, Query(pattern=MONTH)] = None,
) -> UsageView:
    store = _store(request)
    label, start, end = _month_range(month)
    workspace = principal.workspace_id
    totals = await asyncio.to_thread(store.totals, workspace, start, end)
    today = await asyncio.to_thread(store.leases_today, workspace)
    quotas = await asyncio.to_thread(store.quotas, workspace)
    exempt = workspace == BOOTSTRAP_WORKSPACE_ID
    return UsageView(
        workspace_id=workspace,
        month=label,
        workflows=_count(totals, "workflow_completed"),
        videos=_count(totals, "video_rendered"),
        rendered_seconds=_sum(totals, "video_rendered"),
        stored_bytes=int(_sum(totals, "media_stored")),
        leases={t.key: t.events for t in totals if t.kind == "account_lease"},
        quotas=[

                platform=platform,
                daily_leases=None if exempt else limit,
                used_today=today.get(platform, 0),
                remaining_today=None if exempt else max(0, limit - today.get(platform, 0)),
            )
            for platform, limit in quotas.items()
        ],
    )

// The caller's workspace usage (spec 2026-10-20 metering, 2.4).
import type { components } from "@/api/generated/control-plane";

export type UsageView = components["schemas"]["UsageView"];

type Fetch = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>;

export function createUsageClient(doFetch: Fetch = (input, init) => fetch(input, init)) {
  return {
    async get(month?: string): Promise<UsageView> {
      const query = month ? `?month=${encodeURIComponent(month)}` : "";
      const response = await doFetch(`/api/v1/usage${query}`);
      if (!response.ok) throw new Error(`usage_request_failed_${response.status}`);
      return (await response.json()) as UsageView;
    },
  };
}

export type UsageClient = ReturnType<typeof createUsageClient>;
export const usageClient = createUsageClient();
```
