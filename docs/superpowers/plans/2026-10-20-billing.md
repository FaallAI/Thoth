# Billing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every workspace a plan with a monthly allowance of workflows and videos, enforce it where work starts, sell paid plans through Xendit invoices, and build public sign-up behind a flag.

**Architecture:**
- **Data:** migration `0016` adds four tables: `plans` (seeded with `free`), `subscriptions`, `invoices` and the `allowance_uses` ledger.
- **`BillingStore`** (SQLAlchemy, synchronous) owns plans, subscriptions (lazy free row, roll-forward, operator grants) and the allowance ledger. It admits a unit under `FOR NO KEY UPDATE` on the subscription row, and handles invoice settlement.
- **Enforcement:**
  - `WorkflowRunService.start` consumes a `workflow` unit before the Temporal start and releases it if the start fails.
  - `RenderJobService` consumes a `video` unit before reserving a job and releases it on any close.
  - A global handler turns `PlanLimitReached` into 402.
- **Payments:** a small `XenditInvoices` adapter creates invoices. A token-verified public webhook settles them.
- **Surfaces:** user and admin routes, the CLI, and a dashboard Billing page.
- **Sign-up:** a settings flag relaxes the Google-domain and GitHub-organization rules.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 ORM, Alembic SQL revisions, httpx (Xendit, `httpx.MockTransport` in tests), React 19 + Bun tests, the Docker stack smoke.

**Spec:** `docs/superpowers/specs/2026-10-20-billing-design.md`

## Global Constraints

- **Currency:** rupiah only; `price_idr` is an integer `>= 0`.
- **No plan values in code:** migration `0016` seeds only `free` (`Free`, Rp0, 3 workflows, 1 video, 30 days, active). The `free` plan cannot be deactivated.
- **`ws_bootstrap` is exempt:** no allowance, never billed, and checkout answers 409 `operator_workspace`.
- **Plan limit:** 402 with body `{"detail": {"code": "plan_limit_reached", "kind": …, "used": …, "allowance": …, "period_end": …}}`.
- **Billing tables unavailable during an allowance check:** 503 `billing_unavailable`. The start is refused, never admitted.
- **No billing store configured** (no editor database: tests and dev): no enforcement, as with the other optional stores.
- **Xendit:**
  - `POST https://api.xendit.co/v2/invoices`, HTTP Basic auth with the secret key as the user name and an empty password;
  - JSON request fields `external_id`, `amount`, `payer_email`, `description`, `invoice_duration` (86400), `currency` (`IDR`), `success_redirect_url` and `failure_redirect_url`;
  - the response carries `id` and `invoice_url`.
- **Webhook:**
  - `POST /billing/webhooks/xendit`; header `x-callback-token` compared in constant time with `THOTH_XENDIT_CALLBACK_TOKEN`;
  - JSON fields `external_id`, `status` (`PAID`, `SETTLED` or `EXPIRED`) and `paid_amount`;
  - an unknown invoice answers 200 and is ignored.
- **Secrets:** `THOTH_XENDIT_SECRET_KEY` and `THOTH_XENDIT_CALLBACK_TOKEN` are never logged or returned.
- **Sign-up flag:** `THOTH_AUTH_PUBLIC_SIGNUP` defaults to `false`.
- **Commits:** exactly one `git commit -m "<subject>"`, with no body, no trailer and no AI attribution.
- **Staging:** never stage `.superpowers/`, `graphify-out/`, `.serena/` or `design/`. Files under `docs/superpowers/` need `git add -f`.
- **Tests:** offline only. Python runs through `make test T=…` from WSL; PostgreSQL through `bash scripts/dev/pytest-postgres.sh <file>`.
- **File edits:** with the Edit tool, or with Python scripts written to the scratchpad. Bash heredocs that contain nested triple quotes break in the Bash tool.

## Review Focus

1. **A client retries a workflow start with the same Idempotency-Key after the first succeeded:** it must be admitted and must not consume a second unit. Pinned in Task 3.
2. **A render closed by any path (dispatch failure, the renderer's `failed` or `cancelled`, the expiry sweeper):** it gives its unit back exactly once. Pinned in Task 3.
3. **A paid subscription past `period_end` when the next start arrives:** it falls back to `free` before the allowance is counted, so the user is held to free, not to the expired plan. Pinned in Task 2.
4. **A webhook replayed after the first `PAID`:** the subscription is extended once. A replay after an `EXPIRED` changes nothing. Pinned in Task 4.
5. **Two new workspaces' first starts arriving together:** the lazy free row is created once, and no start fails with an integrity error. Pinned in Task 2.

```sql
CREATE TABLE plans (
    plan_id TEXT PRIMARY KEY CHECK (plan_id ~ '^[a-z0-9-]{1,32}$'),
    name TEXT NOT NULL CHECK (length(name) BETWEEN 1 AND 60),
    price_idr BIGINT NOT NULL CHECK (price_idr >= 0),
    workflows_per_period INTEGER NOT NULL CHECK (workflows_per_period >= 0),
    videos_per_period INTEGER NOT NULL CHECK (videos_per_period >= 0),
    period_days INTEGER NOT NULL DEFAULT 30 CHECK (period_days BETWEEN 1 AND 366),
    active BOOLEAN NOT NULL DEFAULT true,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
INSERT INTO plans (plan_id, name, price_idr, workflows_per_period, videos_per_period, period_days)
VALUES ('free', 'Free', 0, 3, 1, 30);

CREATE TABLE subscriptions (
    workspace_id TEXT PRIMARY KEY REFERENCES workspaces (workspace_id),
    plan_id TEXT NOT NULL REFERENCES plans (plan_id),
    period_start TIMESTAMPTZ NOT NULL,
    period_end TIMESTAMPTZ NOT NULL,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE invoices (
    invoice_id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL REFERENCES workspaces (workspace_id),
    plan_id TEXT NOT NULL REFERENCES plans (plan_id),
    amount_idr BIGINT NOT NULL CHECK (amount_idr >= 0),
    status TEXT NOT NULL CHECK (status IN ('pending', 'paid', 'expired', 'failed')),
    provider_invoice_id TEXT,
    invoice_url TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    paid_at TIMESTAMPTZ
);
CREATE INDEX invoices_workspace ON invoices (workspace_id, created_at DESC);

CREATE TABLE allowance_uses (
    use_id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL REFERENCES workspaces (workspace_id),
    kind TEXT NOT NULL CHECK (kind IN ('workflow', 'video')),
    ref TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL,
    released_at TIMESTAMPTZ,
    UNIQUE (workspace_id, kind, ref)
);
CREATE INDEX allowance_uses_period ON allowance_uses (workspace_id, kind, created_at);
```

```python
"""Billing's domain: plans, subscriptions and the allowance (spec 2026-10-20 billing)."""

from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime
from hashlib import sha256
from typing import Literal

FREE_PLAN_ID = "free"
Kind = Literal["workflow", "video"]


class PlanLimitReached(Exception):
    """The workspace used this period's allowance of `kind` (spec 1.4): HTTP 402."""

    def __init__(self, kind: str, used: int, allowance: int, period_end: datetime) -> None:
        super().__init__("plan_limit_reached")
        self.kind, self.used, self.allowance, self.period_end = kind, used, allowance, period_end


class BillingUnavailable(RuntimeError):
    """The billing tables could not be read: a start is refused, never admitted (spec 3.3)."""


class UnknownPlan(LookupError):
    pass


class InvalidPlan(ValueError):
    pass


@dataclass(frozen=True)
class PlanView:
    plan_id: str
    name: str
    price_idr: int
    workflows_per_period: int
    videos_per_period: int
    period_days: int
    active: bool


@dataclass(frozen=True)
class SubscriptionView:
    workspace_id: str
    plan_id: str
    period_start: datetime
    period_end: datetime


@dataclass(frozen=True)
class AllowanceView:
    workspace_id: str
    unlimited: bool
    plan: PlanView | None
    period_start: datetime | None
    period_end: datetime | None
    workflows_used: int
    workflows_allowed: int | None
    videos_used: int
    videos_allowed: int | None


@dataclass(frozen=True)
class InvoiceView:
    invoice_id: str
    plan_id: str
    amount_idr: int
    status: str
    invoice_url: str | None
    created_at: datetime
    paid_at: datetime | None


def workflow_ref(actor_type: str, actor_id: str, idempotency_key: str) -> str:
    """The ledger key of one workflow start: an idempotent retry reuses it."""
    return sha256(f"{actor_type}\0{actor_id}\0{idempotency_key}".encode()).hexdigest()
```

```python
"""Plans, subscriptions, invoices and the allowance ledger in PostgreSQL (editor migration 0016).

Synchronous like the other stores; async callers use `asyncio.to_thread`. A database error is
`BillingUnavailable`.
"""

from __future__ import annotations

import re
import uuid
from collections.abc import Callable
from datetime import UTC, datetime, timedelta

from sqlalchemy import create_engine, func, select
from sqlalchemy.engine import Engine, make_url
from sqlalchemy.exc import IntegrityError, SQLAlchemyError
from sqlalchemy.orm import Session, sessionmaker

from thoth_control_plane.auth.models import BOOTSTRAP_WORKSPACE_ID
from thoth_control_plane.billing import (
    FREE_PLAN_ID,
    AllowanceView,
    BillingUnavailable,
    InvalidPlan,
    PlanLimitReached,
    PlanView,
    SubscriptionView,
    UnknownPlan,
)
from thoth_control_plane.infrastructure.billing_models import (
    AllowanceUseRow,
    PlanRow,
    SubscriptionRow,
)

PLAN_ID = re.compile(r"^[a-z0-9-]{1,32}$")


def _plan(row: PlanRow) -> PlanView:
    return PlanView(
        row.plan_id, row.name, row.price_idr, row.workflows_per_period,
        row.videos_per_period, row.period_days, row.active,
    )


class BillingStore:
    def __init__(
        self, engine: Engine, clock: Callable[[], datetime] = lambda: datetime.now(UTC)
    ) -> None:
        self._sessions = sessionmaker(engine, expire_on_commit=False)
        self._clock = clock

    @classmethod
    def connect(cls, database_url: str) -> BillingStore:
        url = make_url(database_url).set(drivername="postgresql+psycopg")
        return cls(
            create_engine(
                url, pool_pre_ping=True, pool_size=2, max_overflow=2, hide_parameters=True,
                connect_args={"connect_timeout": 10},
            )
        )

    # --- plans ---------------------------------------------------------------------------

    def plans(self, active_only: bool = False) -> list[PlanView]:
        query = select(PlanRow).order_by(PlanRow.price_idr, PlanRow.plan_id)
        if active_only:
            query = query.where(PlanRow.active.is_(True))
        with self._guard() as session:
            return [_plan(row) for row in session.scalars(query)]

    def plan(self, plan_id: str) -> PlanView | None:
        with self._guard() as session:
            row = session.get(PlanRow, plan_id)
            return None if row is None else _plan(row)

    def set_plan(
        self,
        plan_id: str,
        *,
        name: str,
        price_idr: int,
        workflows: int,
        videos: int,
        period_days: int,
        active: bool,
    ) -> PlanView:
        if (
            not PLAN_ID.fullmatch(plan_id)
            or not 1 <= len(name.strip()) <= 60
            or min(price_idr, workflows, videos) < 0
            or not 1 <= period_days <= 366
            or (plan_id == FREE_PLAN_ID and not active)
        ):
            raise InvalidPlan("invalid_plan")
        with self._guard(write=True) as session:
            row = session.get(PlanRow, plan_id)
            if row is None:
                row = PlanRow(plan_id=plan_id)
                session.add(row)
            row.name, row.price_idr = name.strip(), price_idr
            row.workflows_per_period, row.videos_per_period = workflows, videos
            row.period_days, row.active, row.updated_at = period_days, active, self._clock()
            return _plan(row)

    # --- subscriptions -------------------------------------------------------------------

    def subscription(self, workspace_id: str) -> SubscriptionView:
        self._ensure(workspace_id)
        with self._guard(write=True) as session:
            row = self._current(session, workspace_id, lock=False)
            return SubscriptionView(row.workspace_id, row.plan_id, row.period_start, row.period_end)

    def grant(self, workspace_id: str, plan_id: str, days: int) -> SubscriptionView:
        """An operator grant: `days` of `plan_id` starting now, with no payment."""
        self._ensure(workspace_id)
        with self._guard(write=True) as session:
            if session.get(PlanRow, plan_id) is None:
                raise UnknownPlan(plan_id)
            row = self._current(session, workspace_id, lock=True)
            now = self._clock()
            row.plan_id, row.period_start = plan_id, now
            row.period_end, row.updated_at = now + timedelta(days=days), now
            return SubscriptionView(row.workspace_id, row.plan_id, row.period_start, row.period_end)

    # --- the allowance -------------------------------------------------------------------

    def consume(self, workspace_id: str, kind: str, ref: str) -> bool:
        """Admit one unit of `kind`, or raise `PlanLimitReached`; True when newly taken."""
        if workspace_id == BOOTSTRAP_WORKSPACE_ID:
            return False
        self._ensure(workspace_id)
        with self._guard(write=True) as session:
            sub = self._current(session, workspace_id, lock=True)
            existing = session.scalar(
                select(AllowanceUseRow).where(
                    AllowanceUseRow.workspace_id == workspace_id,
                    AllowanceUseRow.kind == kind,
                    AllowanceUseRow.ref == ref,
                )
            )
            if existing is not None and existing.released_at is None:
                return False
            plan = session.get(PlanRow, sub.plan_id)
            allowance = plan.workflows_per_period if kind == "workflow" else plan.videos_per_period
            used = self._used(session, workspace_id, kind, sub.period_start)
            if used >= allowance:
                raise PlanLimitReached(kind, used, allowance, sub.period_end)
            now = self._clock()
            if existing is not None:
                existing.released_at, existing.created_at = None, now
            else:
                session.add(
                    AllowanceUseRow(
                        use_id=f"use_{uuid.uuid4().hex}", workspace_id=workspace_id,
                        kind=kind, ref=ref, created_at=now,
                    )
                )
            return True

    def release(self, workspace_id: str, kind: str, ref: str) -> None:
        with self._guard(write=True) as session:
            row = session.scalar(
                select(AllowanceUseRow).where(
                    AllowanceUseRow.workspace_id == workspace_id,
                    AllowanceUseRow.kind == kind,
                    AllowanceUseRow.ref == ref,
                    AllowanceUseRow.released_at.is_(None),
                )
            )
            if row is not None:
                row.released_at = self._clock()

    def allowance(self, workspace_id: str) -> AllowanceView:
        if workspace_id == BOOTSTRAP_WORKSPACE_ID:
            return AllowanceView(workspace_id, True, None, None, None, 0, None, 0, None)
        self._ensure(workspace_id)
        with self._guard(write=True) as session:
            sub = self._current(session, workspace_id, lock=False)
            plan = _plan(session.get(PlanRow, sub.plan_id))
            return AllowanceView(
                workspace_id, False, plan, sub.period_start, sub.period_end,
                self._used(session, workspace_id, "workflow", sub.period_start),
                plan.workflows_per_period,
                self._used(session, workspace_id, "video", sub.period_start),
                plan.videos_per_period,
            )

    # --- internals -----------------------------------------------------------------------

    def _guard(self, write: bool = False):
        """A session whose database errors become `BillingUnavailable`."""
        store = self

        class _Guarded:
            def __enter__(self) -> Session:
                self._ctx = store._sessions.begin() if write else store._sessions()
                return self._ctx.__enter__()

            def __exit__(self, kind, error, trace):
                try:
                    handled = self._ctx.__exit__(kind, error, trace)
                except SQLAlchemyError as failure:
                    raise BillingUnavailable("billing_unavailable") from failure
                if isinstance(error, SQLAlchemyError):
                    raise BillingUnavailable("billing_unavailable") from error
                return handled

        return _Guarded()

    def _ensure(self, workspace_id: str) -> None:
        """Create the lazy free row; a racing creator's row is just as good."""
        try:
            with self._sessions.begin() as session:
                if session.get(SubscriptionRow, workspace_id) is not None:
                    return
                free = session.get(PlanRow, FREE_PLAN_ID)
                if free is None:
                    raise BillingUnavailable("free_plan_missing")
                now = self._clock()
                session.add(
                    SubscriptionRow(
                        workspace_id=workspace_id, plan_id=FREE_PLAN_ID, period_start=now,
                        period_end=now + timedelta(days=free.period_days), updated_at=now,
                    )
                )
        except IntegrityError:
            return
        except SQLAlchemyError as error:
            raise BillingUnavailable("billing_unavailable") from error

    def _current(self, session: Session, workspace_id: str, *, lock: bool) -> SubscriptionRow:
        """The subscription, rolled forward past `period_end` (spec 1.2)."""
        row = session.get(
            SubscriptionRow, workspace_id, with_for_update={"key_share": True} if lock else None
        )
        now = self._clock()
        if now >= row.period_end:
            free = session.get(PlanRow, FREE_PLAN_ID)
            row.plan_id, row.period_start = FREE_PLAN_ID, now
            row.period_end, row.updated_at = now + timedelta(days=free.period_days), now
        return row

    @staticmethod
    def _used(session: Session, workspace_id: str, kind: str, since: datetime) -> int:
        return int(
            session.scalar(
                select(func.count())
                .select_from(AllowanceUseRow)
                .where(
                    AllowanceUseRow.workspace_id == workspace_id,
                    AllowanceUseRow.kind == kind,
                    AllowanceUseRow.released_at.is_(None),
                    AllowanceUseRow.created_at >= since,
                )
            )
            or 0
        )
```

```python
def _race(calls) -> list[object]:
    barrier = threading.Barrier(len(calls))
    results: list[object] = []

    def run(call) -> None:
        barrier.wait()
        try:
            results.append(call())
        except PlanLimitReached as refused:
            results.append(refused.kind)
        except BaseException as error:  # a thread's exception would otherwise vanish
            results.append(error)

    threads = [threading.Thread(target=run, args=(call,)) for call in calls]
    for thread in threads:
        thread.start()
    for thread in threads:
        thread.join()
    return results
```

```python
"""Xendit invoices over its REST API (spec 2026-10-20 billing, 2.1). The secret key is the
Basic-auth user name with an empty password; it never appears in an error or a log."""

from __future__ import annotations

import logging
from dataclasses import dataclass

import httpx

logger = logging.getLogger(__name__)
BASE_URL = "https://api.xendit.co"
INVOICE_SECONDS = 86400


class PaymentProviderUnavailable(RuntimeError):
    pass


@dataclass(frozen=True)
class ProviderInvoice:
    id: str
    invoice_url: str


class XenditInvoices:
    def __init__(
        self, secret_key: str, *, transport: httpx.AsyncBaseTransport | None = None
    ) -> None:
        self._key = secret_key
        self._transport = transport

    def __repr__(self) -> str:
        return "XenditInvoices()"

    async def create(
        self,
        *,
        external_id: str,
        amount_idr: int,
        payer_email: str,
        description: str,
        success_url: str,
        failure_url: str,
    ) -> ProviderInvoice:
        body = {
            "external_id": external_id,
            "amount": amount_idr,
            "payer_email": payer_email,
            "description": description,
            "invoice_duration": INVOICE_SECONDS,
            "currency": "IDR",
            "success_redirect_url": success_url,
            "failure_redirect_url": failure_url,
        }
        try:
            async with httpx.AsyncClient(
                base_url=BASE_URL, transport=self._transport, timeout=30, auth=(self._key, "")
            ) as http:
                response = await http.post("/v2/invoices", json=body)
        except httpx.HTTPError:
            logger.warning("xendit unreachable")
            raise PaymentProviderUnavailable("payment_provider_unavailable") from None
        if response.status_code >= 300:
            logger.warning("xendit refused an invoice status=%s", response.status_code)
            raise PaymentProviderUnavailable("payment_provider_unavailable")
        try:
            payload = response.json()
            return ProviderInvoice(str(payload["id"]), str(payload["invoice_url"]))
        except (ValueError, KeyError, TypeError):
            raise PaymentProviderUnavailable("payment_provider_unavailable") from None
```

```python
    def open_invoice(self, workspace_id: str, plan_id: str) -> InvoiceView:
        with self._guard(write=True) as session:
            plan = session.get(PlanRow, plan_id)
            if plan is None or not plan.active:
                raise UnknownPlan(plan_id)
            row = InvoiceRow(
                invoice_id=f"inv_{uuid.uuid4().hex}", workspace_id=workspace_id, plan_id=plan_id,
                amount_idr=plan.price_idr, status="pending", created_at=self._clock(),
            )
            session.add(row)
            return _invoice(row)

    def attach_invoice(self, invoice_id: str, provider_id: str, url: str) -> None:
        with self._guard(write=True) as session:
            row = session.get(InvoiceRow, invoice_id)
            row.provider_invoice_id, row.invoice_url = provider_id, url

    def fail_invoice(self, invoice_id: str) -> None:
        with self._guard(write=True) as session:
            row = session.get(InvoiceRow, invoice_id)
            if row is not None and row.status == "pending":
                row.status = "failed"

    def invoices(self, workspace_id: str) -> list[InvoiceView]:
        with self._guard() as session:
            rows = session.scalars(
                select(InvoiceRow)
                .where(InvoiceRow.workspace_id == workspace_id)
                .order_by(InvoiceRow.created_at.desc())
                .limit(50)
            )
            return [_invoice(row) for row in rows]

    def apply_plan(self, workspace_id: str, plan_id: str) -> None:
        """Start or extend `plan_id` now (spec 2.2): a Rp0 checkout or a paid invoice."""
        self._ensure(workspace_id)
        with self._guard(write=True) as session:
            self._start_plan(session, workspace_id, plan_id)

    def settle(self, invoice_id: str, status: str, paid_amount: int | None) -> str:
        """Apply one webhook: only a pending invoice moves, so replays do nothing."""
        with self._guard(write=True) as session:
            row = session.get(InvoiceRow, invoice_id, with_for_update={"key_share": True})
            if row is None:
                return "unknown"
            if row.status != "pending":
                return "ignored"
            if status == "EXPIRED":
                row.status = "expired"
                return "applied"
            if status not in ("PAID", "SETTLED"):
                return "ignored"
            if paid_amount != row.amount_idr:
                return "mismatch"
            row.status, row.paid_at = "paid", self._clock()
            workspace, plan_id = row.workspace_id, row.plan_id
        self.apply_plan(workspace, plan_id)
        return "applied"

    def _start_plan(self, session: Session, workspace_id: str, plan_id: str) -> None:
        plan = session.get(PlanRow, plan_id)
        if plan is None:
            raise UnknownPlan(plan_id)
        row = self._current(session, workspace_id, lock=True)
        now = self._clock()
        if row.plan_id == plan_id and plan_id != FREE_PLAN_ID and now < row.period_end:
            row.period_end += timedelta(days=plan.period_days)
        else:
            row.plan_id, row.period_start = plan_id, now
            row.period_end = now + timedelta(days=plan.period_days)
        row.updated_at = now
```

```python
"""Plans, allowance and checkout for the caller's workspace (spec 2026-10-20 billing)."""

from __future__ import annotations

import asyncio
from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException, Request, status

from thoth_control_plane.api.dependencies import current_principal, require_write
from thoth_control_plane.auth.models import BOOTSTRAP_WORKSPACE_ID, Principal, is_platform_admin
from thoth_control_plane.billing import UnknownPlan
from thoth_control_plane.domain.models import StrictModel
from thoth_control_plane.infrastructure.billing_store import BillingStore
from thoth_control_plane.infrastructure.xendit import PaymentProviderUnavailable

router = APIRouter(tags=["billing"])
Caller = Annotated[Principal, Depends(current_principal)]


class CheckoutRequest(StrictModel):
    plan_id: str


class CheckoutView(StrictModel):
    invoice_id: str | None
    invoice_url: str | None
    applied: bool


def _store(request: Request) -> BillingStore:
    store = request.app.state.billing_store
    if store is None:
        raise HTTPException(status.HTTP_503_SERVICE_UNAVAILABLE, "billing_unavailable")
    return store


@router.post("/billing/checkout", response_model=CheckoutView)
async def checkout(request: Request, body: CheckoutRequest, principal: Caller) -> CheckoutView:
    require_write(request, principal)
    if principal.role not in ("owner", "admin") and not is_platform_admin(principal):
        raise HTTPException(status.HTTP_403_FORBIDDEN, "Not authorized")
    if principal.workspace_id == BOOTSTRAP_WORKSPACE_ID:
        raise HTTPException(status.HTTP_409_CONFLICT, "operator_workspace")
    store = _store(request)
    plan = await asyncio.to_thread(store.plan, body.plan_id)
    if plan is None or not plan.active:
        raise HTTPException(status.HTTP_404_NOT_FOUND, "unknown_plan")
    if plan.price_idr == 0:
        await asyncio.to_thread(store.apply_plan, principal.workspace_id, plan.plan_id)
        return CheckoutView(invoice_id=None, invoice_url=None, applied=True)
    payments = getattr(request.app.state, "payments", None)
    if payments is None:
        raise HTTPException(status.HTTP_503_SERVICE_UNAVAILABLE, "billing_unavailable")
    try:
        invoice = await asyncio.to_thread(store.open_invoice, principal.workspace_id, plan.plan_id)
    except UnknownPlan:
        raise HTTPException(status.HTTP_404_NOT_FOUND, "unknown_plan") from None
    back = f"{request.app.state.settings.THOTH_SITE_ORIGIN}/billing"
    try:
        made = await payments.create(
            external_id=invoice.invoice_id, amount_idr=invoice.amount_idr,
            payer_email=principal.email or "", description=plan.name,
            success_url=back, failure_url=back,
        )
    except PaymentProviderUnavailable:
        await asyncio.to_thread(store.fail_invoice, invoice.invoice_id)
        raise HTTPException(status.HTTP_502_BAD_GATEWAY, "payment_provider_unavailable") from None
    await asyncio.to_thread(store.attach_invoice, invoice.invoice_id, made.id, made.invoice_url)
    return CheckoutView(invoice_id=invoice.invoice_id, invoice_url=made.invoice_url, applied=False)
```

```python
"""Xendit's invoice callback (spec 2026-10-20 billing, 2.2): public, token-verified, idempotent."""

from __future__ import annotations

import asyncio
import logging
from hmac import compare_digest
from typing import Annotated

from fastapi import APIRouter, Header, HTTPException, Request, status

router = APIRouter(tags=["billing"], include_in_schema=False)
logger = logging.getLogger(__name__)


@router.post("/billing/webhooks/xendit")
async def xendit_webhook(
    request: Request,
    token: Annotated[str | None, Header(alias="x-callback-token")] = None,
) -> dict[str, str]:
    settings = request.app.state.settings
    store = request.app.state.billing_store
    expected = settings.THOTH_XENDIT_CALLBACK_TOKEN
    if expected is None or store is None:
        raise HTTPException(status.HTTP_503_SERVICE_UNAVAILABLE, "billing_unavailable")
    if token is None or not compare_digest(token.encode(), expected.get_secret_value().encode()):
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "invalid_token")
    try:
        body = await request.json()
    except ValueError:
        raise HTTPException(status.HTTP_400_BAD_REQUEST, "invalid_body") from None
    invoice_id = str(body.get("external_id") or "")
    paid = body.get("paid_amount")
    outcome = await asyncio.to_thread(
        store.settle,
        invoice_id,
        str(body.get("status") or ""),
        int(paid) if isinstance(paid, (int, float)) else None,
    )
    if outcome in ("unknown", "mismatch"):
        logger.warning("xendit callback not applied outcome=%s", outcome)
    return {"status": outcome}
```

```python
@router.get("/admin/plans/margin", response_model=MarginView)
async def plan_margin(
    request: Request,
    _: Admin,
    start: Annotated[date | None, Query(alias="from")] = None,
    end: Annotated[date | None, Query(alias="to")] = None,
) -> MarginView:
    """Each plan's price against metered cost (spec 1.5); unit prices apply as of now."""
    from thoth_control_plane.api.routes.usage import _bucket

    usage = request.app.state.usage_store
    today = datetime.now(UTC).date()
    begin, finish = start or today.replace(day=1), end or today
    since = datetime.combine(begin, datetime.min.time(), tzinfo=UTC)
    until = datetime.combine(finish, datetime.min.time(), tzinfo=UTC) + timedelta(days=1)
    totals = [] if usage is None else [
        t for rows in (await asyncio.to_thread(usage.totals_by_workspace, since, until)).values()
        for t in rows
    ]
    prices = {} if usage is None else {
        (p.kind, p.key, p.unit): p.usd_per_unit for p in await asyncio.to_thread(usage.prices)
    }
    result = estimate(totals, prices)
    spent = {"workflow": 0.0, "video": 0.0}
    for total, line in zip(totals, result.lines, strict=True):
        bucket = _bucket(total)
        if bucket in spent and line.usd is not None:
            spent[bucket] += line.usd
    workflows = sum(t.events for t in totals if t.kind == "workflow_completed")
    videos = sum(t.events for t in totals if t.kind == "video_rendered")
    per_workflow = spent["workflow"] / workflows if workflows else None
    per_video = spent["video"] / videos if videos else None
    plans = await asyncio.to_thread(_store(request).plans, True)
    return MarginView(
        start=begin,
        end=finish,
        complete=not result.unpriced,
        plans=[
            PlanMargin(
                plan_id=p.plan_id,
                price_idr=p.price_idr,
                workflows_per_period=p.workflows_per_period,
                videos_per_period=p.videos_per_period,
                cost_per_workflow_usd=per_workflow,
                cost_per_video_usd=per_video,
                full_use_cost_usd=None
                if per_workflow is None or per_video is None
                else p.workflows_per_period * per_workflow + p.videos_per_period * per_video,
            )
            for p in plans
        ],
    )
```

```ts
import type { components } from "@/api/generated/control-plane";

export type BillingView = components["schemas"]["BillingView"];
export type CheckoutView = components["schemas"]["CheckoutView"];

type Fetch = (input: RequestInfo | URL, init?: RequestInit) => Promise<Response>;

export function createBillingClient(doFetch: Fetch = (input, init) => fetch(input, init)) {
  return {
    async get(): Promise<BillingView> {
      const response = await doFetch("/api/v1/billing");
      if (!response.ok) throw new Error(`billing_request_failed_${response.status}`);
      return (await response.json()) as BillingView;
    },
    async checkout(planId: string): Promise<CheckoutView> {
      const response = await doFetch("/api/v1/billing/checkout", {
        method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ plan_id: planId }),
      });
      if (!response.ok) throw new Error(`checkout_failed_${response.status}`);
      return (await response.json()) as CheckoutView;
    },
  };
}

export type BillingClient = ReturnType<typeof createBillingClient>;
export const billingClient = createBillingClient();
```
